# SEO_QLChiTieu

Dự án Quản lý chi tiêu cá nhân (Expense Management Application).

## Công nghệ sử dụng
- React 19 + TypeScript
- Vite
- Tailwind CSS v4

## Hướng dẫn cài đặt & Chạy ứng dụng
```bash
# Cài đặt thư viện
npm install
# hoặc pnpm install

# Khởi chạy môi trường phát triển
npm run dev
```
